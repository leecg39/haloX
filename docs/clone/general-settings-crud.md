# 일반 설정: 수집 기본값과 자동 프롬프트

2026-10-24. 원본 일반 화면 `d428a95a66d7c749.json`의 수집 기본 언어·국가와 프롬프트 자동 생성 설정을 서버에 연결했다. `/app/settings`와 `?tab=general`에서 사용한다. **S12 전체 완료는 아니다. 계정별 한국어/영어 인터페이스 전환과 전체 관리자 화면 번역은 남아 있다.** 현재 화면은 한국어이며 영어 전환이 아직 제공되지 않음을 표시한다. 전체 범위는 [작업표](full-crud-tasks.md)를 따른다.

## 설정 모델과 API

`workspaces`의 `default_analysis_language`, `default_analysis_country`, `auto_generate_prompts`에 저장한다. 이전 자료의 필드 누락은 한국어·대한민국·자동 생성 켜짐으로 해석하며 기존 `auto_generate_prompts=false`는 유지한다. 언어 ko/en/ja/zh, 국가 KR/US/JP/CN을 지원한다.

`GET /api/v1/general-settings?workspace_id=...`는 현재 설정·워크스페이스 이름·revision·수정 가능 여부를 반환한다. 기타 메뉴 조회 권한이 필요하다. `POST`의 `update`/`reset`은 현재 워크스페이스 소유자·관리자 및 기타 메뉴 쓰기 권한을 확인한다. `expected_revision`이 다르면 409로 거절한다. 실패와 충돌은 입력을 유지한다. 초기화는 수집 기본값만 되돌리며 브랜드·정책 파일·기타 설정을 덮어쓰지 않는다. 설정은 워크스페이스에 종속되어 삭제 시 함께 정리된다.

공개 REST의 임의 `settings`/`auto_generate_prompts` 변경을 차단했다. 일반 설정은 전용 명령으로만 수정한다. 내부 도메인 검증에서도 기본 언어·국가·불리언의 형식을 검사한다. 개인 화면 언어는 워크스페이스 설정에 혼합하지 않았다.

## 실제 기본값 적용

새 키워드·키워드 세트·아이디어·GEO 프롬프트의 언어/국가 누락 시 현재 워크스페이스 기본값을 적용한다. 키워드/프롬프트 집계 API는 같은 저장소 읽기에서 기본값을 함께 반환하며, 생성 폼은 이를 초기 선택으로 사용한다. API/MCP의 프롬프트 등록도 같은 기본값을 사용한다. 명시한 언어/국가, 기존 항목 수정·재수집, 후보 채택 시 원본에 저장된 언어/국가는 유지한다. 검색/분석의 기존 기간·전체 언어 필터를 강제로 바꾸지 않는다.

## 자동 질문 등록

키워드 등록/아이디어 채택/갭 후보 채택/MCP 키워드 수집에서 새 키워드를 만들 때 설정을 적용한다. 프롬프트는 키워드를 포함한 언어별 문장 규칙으로 생성한다. 한국어·영어·일본어·중국어 문장 규칙을 지원하며 API에서 다른 언어 코드를 명시하면 원래 키워드 문구를 보존한다. LLM 의미 확장이나 번역 결과로 표시하지 않는다.

- 같은 문구(NFKC/공백/대소문자 정규화)·언어·국가의 기존 질문은 재사용하고 연결한다.
- 새 질문은 `origin=keyword-template`와 원본 키워드 ID를 보존하며 화면에 문장 규칙으로 자동 생성됐음을 표시한다. 키워드 삭제 시 연결/원본 ID는 정리하고 질문은 보존한다.
- 새 질문은 `prompt_create` 1회를 예약·확정한다. 키워드·검색 자료·질문·연결·사용량을 같은 트랜잭션에서 저장하며 한도/수집 실패 시 전부 롤백한다.
- 자동 질문은 미분류로 등록하고 AI 응답을 실행하거나 예약 세트를 만들지 않는다. 사용자는 프롬프트 화면에서 수정·실행하거나 예약 세트에 배치한다. 기존 질문을 재사용할 때 그 질문의 세트·예약 상태를 변경하지 않는다.
- 설정 끄기는 이후 새 등록에만 적용하며 기존 질문/예약을 중단하거나 삭제하지 않는다. 키워드 재수집에서는 질문을 다시 생성하지 않는다.
- 이미 처리한 키워드 생성 요청 키를 다시 쓰면 거절한다. 키워드/자동 질문 삭제 뒤에도 같은 요청으로 다시 생성하거나 한도를 우회할 수 없다.

## API 권한과 사용량 표시

자동 생성이 켜진 워크스페이스의 MCP/HTTP `collect_keywords`는 `seo:write`와 `prompts:write`를 모두 요구한다. 도구 목록에도 현재 권한을 반영한다. 저장된 재요청 결과는 최초 작업에 필요했던 권한을 함께 보존하므로 설정을 끄고 질문 권한을 회수해도 이전 결과를 통해 질문 정보를 읽지 못한다.

상단 프롬프트 사용량의 고정 50%를 현재 선택 워크스페이스의 실제 예약/확정 집계로 바꿨다. 함수 작업 성공·화면 이동·창 포커스 시 갱신한다. 사용량 탭도 데모 워크스페이스 고정 ID 대신 선택한 ID를 사용한다. 오류/로딩 시 캡처 숫자를 유지하지 않고 미확인으로 표시하며 다른 워크스페이스의 늦은 응답을 버린다. 초기화 날짜나 결제 금액을 추정하지 않는다. 원장의 정산/월별 전환과 실제 결제는 S06/S14의 별도 범위다.

## 검증

단위 7개는 설정 저장/재개방/초기화/충돌/권한/REST 차단, 모든 생성 경로의 기본값과 명시 값 보존, 자동 질문·연결·미실행/미예약·차감/재사용/재요청, 생성 한도 초과 시 전체 롤백, 원본 키워드 삭제 후 질문 보존/참조 해제/수정/삭제, API 권한 회수 후 재요청 차단을 검사한다. 기존 키워드/갭의 사용량 검증은 키워드와 자동 질문 각각의 예약을 포함하도록 갱신했다.
