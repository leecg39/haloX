# DeepL 자동 번역과 실행 이력

2026-10-23. P11 `/app/exports`의 자동 번역을 구현했다. 제목·본문·검색 메타 정보를 DeepL로 전송하고, 실제 응답을 원문 버전에 연결된 `article_translations`로 저장한다. 수동 번역과 동일하게 편집·검토·삭제할 수 있고, **사용 준비로 변경한 결과만 파일 생성과 WordPress 게시에 사용**한다. 전체 메뉴 목표의 진행 상태는 [작업표](full-crud-tasks.md)를 따른다.

## 설정과 사용

서버 `.env.local` 또는 배포 환경에 `DEEPL_API_KEY`, `DEEPL_API_PLAN=free` 또는 `pro`를 설정하고 재시작한다. 키는 서버에서만 읽는다. 키가 없거나 플랜 값이 잘못되면 실행 이력/사용량을 만들기 전에 HTTP 503 `TRANSLATION_NOT_CONFIGURED`로 거절한다. 조회 API는 설정 여부만 반환한다.

워크스페이스 소유자·관리자가 번역문 관리 또는 번역 실행 탭에서 **자동 번역**을 열고, 콘텐츠/원문 언어/번역 언어와 전송 내용을 확인한다. 원문 전송 및 비용 가능성 확인을 선택해야 실행된다. 한국어·영어·일본어·중국어·스페인어를 지원하며 영어 결과는 EN-US, 중국어 결과는 ZH-HANS다. 원문과 같은 언어는 거절한다.

DeepL 비용과 별도로 콘텐츠 생성 사용량 1회를 예약한다. 성공 시 확정, 첫 요청의 확실한 거절 시 반환한다. 부분 성공 또는 응답 불명은 1회를 사용한 것으로 처리한다. 제공자가 반환한 `billed_characters`를 합산하며, 값이 없거나 응답이 불명확하면 일부/미확인으로 표시한다. DeepL 계정의 최종 청구를 대신하는 원장이 아니다.

## 모델과 실행 정책

| 저장 위치 | 내용 |
|---|---|
| `translation_runs` | 원문 스냅샷·고정 source_identity·언어·상태·revision·진행 횟수·확인된 과금 문자·부분 결과·메모·사용량 예약·생성된 번역문 ID |
| `article_translations` | `origin=deepl`, `status=draft`, 실제 번역 필드, 원문/실행 참조 및 원문 스냅샷 |
| 비공개 `translation_requests` | 사용자/워크스페이스/요청 키/요청 지문/실행 ID. REST 테이블 밖에 보관 |

외부 통신 전에 실행 및 사용량 예약을 원자적으로 저장하고, SQLite 쓰기 잠금 밖에서 DeepL을 호출한다. 각 응답을 확인한 즉시 부분 결과를 저장한다. 같은 요청 키는 재시작 후에도 기존 결과만 반환하며, 다른 내용에 키를 재사용하면 거절한다. 이력을 삭제해도 요청 키 기록은 남아 재전송되지 않는다.

같은 원문 버전/언어에 진행 중·결과 불명 실행 또는 기존 번역문이 있으면 새 자동 번역을 막는다. 진행 중·결과 불명 상태에서는 수동 번역 등록도 중복되지 않게 막는다. 완료된 번역문을 삭제한 뒤 새 창에서 명시적으로 다시 실행하면 새 비용이 발생할 수 있다.

상태는 `running` → `succeeded`, `failed`, `unknown`이다. timeout·잘못된 응답·5xx·리디렉션은 결과 불명으로 남기며 자동 재시도하지 않는다. 4xx는 확실한 거절로 처리하되 이전에 받은 부분 결과와 사용량은 보존한다. 프로세스 중단 시 `running`이 남을 수 있다. 마지막 진행으로부터 5분 후 관리자가 과금 가능성을 확인하여 `abandoned`로 종료할 수 있으며, 이는 원격 취소나 환불이 아니다. 종료 후 메모 수정/이력 삭제가 가능하다.

실행 도중 원문이 변경되어도 선택 당시 원문 스냅샷을 사용한다. 원문 삭제 시 참조만 해제하고 결과를 보존한다. 원문/번역문/실행을 삭제하면 관련 참조를 해제한다. 진행 중·결과 불명 실행이 있으면 워크스페이스 삭제를 막고, 정리된 워크스페이스 삭제 시 요청 키를 포함해 모두 삭제한다. 실행 중 멤버십이 철회되거나 저장 실패가 발생하면 실행이 미확정 상태로 남을 수 있으며 현재 관리자가 이력을 정리한다.

## 외부 요청과 길이

- Free/Pro의 고정 공식 HTTPS 주소로만 전송한다. 인증 헤더는 `DeepL-Auth-Key`다. 공개 DNS 검증·주소 고정·인증서 검증·리디렉션 차단·10초 제한·2MiB 응답 제한은 공통 `public-json.ts`가 담당한다.
- 원문 최대 100,000자를 줄 경계 우선으로 분리하고 Unicode 문자와 공백을 보존한다. 요청당 JSON은 120KiB 이하, text 항목은 50개 이하로 묶어 전송한다. API의 전체 128KiB 제한에 헤더 여유를 둔다.
- `preserve_formatting=true`를 요청하지만 Markdown 구조·코드·URL이 완전히 보존되는 파서가 아니다. 용어와 서식 검토가 필요하다.
- 번역 길이 증가를 고려해 제목/검색 제목 1,000자, 본문 400,000자, 검색 설명 5,000자까지 편집·내보내기·WordPress 전송이 가능하다. 초과 결과는 자르거나 완성된 번역문으로 꾸미지 않고 실패 이력의 확인된 부분 결과로 보관한다.

근거: [DeepL 번역 API](https://developers.deepl.com/api-reference/translate/request-translation), [요청 크기·과금 문자 기준](https://developers.deepl.com/docs/resources/usage-limits). 외부 API 원문 오류나 API 키를 클라이언트 오류·실행 이력에 저장하지 않는다.

## API

- `GET /api/v1/exports?workspace_id=...`: 기존 자료와 `translation_runs`, `translation_configured` 조회. 워크스페이스 멤버십 필수.
- `translate-content-v2`: `workspace_id`, `job_id`, `expected_content_revision`, `source_locale`, `locale`, `idempotency_key`, `confirm=true`. 전용 서버 오케스트레이터에서 처리한다. DB 엔진의 옛 데모 경로는 거절한다.
- `translation-run-update/delete`: `run_id`, `expected_revision`, update는 `notes`만 변경한다. 진행 중/결과 불명에는 사용 불가.
- `translation-run-resolve`: `run_id`, `expected_revision`, `confirm=true`. 마지막 진행 이후 5분 제한.
- 모든 실행 명령은 소유자·관리자 전용이다. 공개 REST로 번역문·실행·사용량을 조작할 수 없다. 다른 워크스페이스의 원문이나 실행 ID를 사용할 수 없다.

## 검증과 운영 한계

단위 **129/129**, E2E **44/44**, 백엔드 **22/22**, 타입 검사·프로덕션 빌드 통과. 새 단위 8개는 UTF-8 분할, 요청 인증/고정 주소/응답 검증, 요청 중복·재시작·삭제 기록, 잠금 없는 통신, 부분 실패·사용량, 불명 결과 수동 종료, 권한, 확장된 번역문을 검증한다. 새 E2E 3개는 설정 누락 503/입력 유지, 실제 서비스 저장→검토→다운로드, timeout 중복 클릭/수동 종료를 확인한다.

외부 DeepL 통신은 주입한 테스트 클라이언트이며, **실제 유료 번역·품질·과금 검증을 수행하지 않았다**. 현재 서버에는 DeepL API 키가 없다. 실제 요청은 서버 키 설정 후 사용자가 원문을 확인하고 실행해야 한다. 호출은 현재 Node 요청 수명 안에서 수행하며 범용 백그라운드 큐/자동 복구는 F10에 남아 있다.

Ego Lite에서는 설정 누락 오류·선택 언어 유지·모바일 스크롤/가로 넘침을 확인했다. 검증용 워크스페이스는 삭제했다. [데스크톱](evidence/2026-10-23-automatic-translation.png), [모바일](evidence/2026-10-23-automatic-translation-mobile.png).
