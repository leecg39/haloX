# 전체 메뉴 CRUD 최종 인수 기록

검증 기준일은 2026-10-25다. 기계 판독 가능한 상세 매핑은 [crud-coverage.json](crud-coverage.json)에 있으며 `npm run verify:crud-coverage`가 매니페스트를 다시 읽고 누락과 증빙 파일을 검사한다.

## Q01 경로·모델·API·테스트 매핑

캡처 매니페스트 363개 중 기능 완료 대상은 278개다. 캡처 당시 원본이 404였던 73개와 리디렉션 전용 12개는 완료 수에서 제외했다. 완료 대상과 보충 라이브 경로는 26개 서버 도메인에 모두 매핑되며 미매핑 경로는 0개다. 캡처 이후 만든 운영자 CMS, 계정·초대 경로와 실제 동적 상세 패턴 14개는 보충 경로로 별도 기록했다.

매핑은 쿼리 탭과 동적 상세 경로를 그대로 보존한다. 예를 들어 키워드 상세의 여섯 탭은 `keywords` 도메인, SEO/GEO 분석 탭은 `analyses`, 설정 탭은 account/workspace/tags/brand/earned/exports/google/notifications/billing/api/general 도메인으로 연결한다. 각 도메인에는 실제 모델, `/api/v1` 엔드포인트, E2E 파일과 구현 문서가 기록되어 있으며 검증 스크립트는 참조 파일이 없으면 실패한다.

## Q02 실패·빈 상태·권한·로딩·모바일·키보드

앱 경로는 공통 `ClonePage`, `WorkspaceProvider`, `LiveModal`, `ErrorState`와 도메인별 라이브 화면을 사용한다. 이 공통 층에서 권한 확인 중/권한 없음, 읽기 전용, 로딩 `role=status`, 오류 `role=alert`와 재시도, 모달 포커스·ESC·키보드 제출을 처리한다. 각 도메인 E2E는 저장 후 새로고침, 실패 시 입력 보존, 사용자·워크스페이스 격리와 모바일 조작을 검증한다. 목록 화면은 빈 데이터와 검색 결과 없음 상태를 실제 서버 응답으로 구분한다.

Ego 관측에서 기록한 음수 누적 통계도 재확인했다. 대시보드 총계는 저장 레코드 배열의 길이로 계산되어 0 이상이고, 점수와 비율은 0~100 범위다. 음수는 현재 기간과 직전 동일 길이 기간의 차이인 `변화(%p)`에서만 정상적으로 표시된다. 관측 단위 테스트가 삭제 후 총계 0, 모든 총계의 비음수 정수, 모든 점수의 0~100 범위를 확인한다.

공개 195개 경로는 같은 공개 콘텐츠 렌더러와 버전형 CMS를 공유한다. 한국어·영어 도입 문의는 같은 서버 검증, 중복·속도 제한, 동의 처리와 운영자 문의함을 사용한다. 공개 경로의 원본 404는 관리 콘텐츠를 새로 게시하기 전까지 기능 완료로 세지 않는다.

## Q03 CRUD·재집계·재시작·격리·백업/복원

도메인별 E2E와 단위 테스트는 생성·조회·수정·삭제, 연관 행 정리, 충돌, 삭제 후 재계산, 저장 후 새로고침을 검증한다. 관측 대시보드, 분석, 전략맵, 브랜드 재분류, 사이트 진단, 감시와 리포트는 원본 변경 후 집계를 다시 계산하거나 생성 시점 스냅샷을 보존하는 계약을 각각 검사한다.

영속 작업은 새 `PersistentHaloXStore` 인스턴스를 만들어 재시작을 모사하며, 예약 GEO·진단·감시·리포트·Google 동기화·계정 정리의 점유/중복 방지와 재개를 검증한다. 전체 E2E에서 한 차례 관측된 SQLite 읽기 경합은 읽기 잠금 획득에도 BUSY/LOCKED 재시도를 적용했고 결정적 경합 단위 테스트와 이후 전체 E2E로 재현 방지를 확인했다. 공개 REST/RPC 우회와 다른 사용자·워크스페이스 접근은 인증·권한 및 각 도메인 격리 테스트가 거부한다.

전체 저장 상태의 백업·복원은 [backup-restore.md](backup-restore.md)의 CLI로 제공한다. SHA-256 변조 탐지, `0600` 파일, 정확한 공개/비공개 상태 왕복, 복원 실패 시 기존 데이터 불변을 단위 테스트로 확인한다.

## Q04 실행 명령

최종 인수에서 아래를 모두 실행해 통과했다.

```bash
npm run verify:crud-coverage
npm run test:unit
npm run verify:backend
npm run typecheck
npm run build
npm run test:e2e
npm run verify:routes -- http://127.0.0.1:3001
```

결과는 단위 테스트 371/371, 백엔드 계약 22/22(RPC 36개, 테이블 59개), E2E 113/113, TypeScript 검사와 Next.js 16.4.2 프로덕션 빌드 성공이다. Supabase SQL 계약도 전체 통과했다. 경로 363개에서 누락·실패·중복 경로·중복 파일·잘못된 항목·누락 자산·외부 자산·위험 URL은 모두 0개였고 원본 404는 73개였다. CRUD 매핑 검증은 완료 대상 278개, 제외 85개, 26개 도메인, 미매핑 0개였다.

SMTP, SOLAPI, OpenAI, Google, NicePay와 실제 WordPress 서버의 유료·외부 요청은 테스트 자격 증명 없이 호출하지 않았다. 구성 누락, 성공 fixture, 중복 방지, 불확실한 응답과 실패 보존은 로컬 테스트로 검증했으며 운영 키를 설정한 뒤 각 제공자 샌드박스/운영 환경에서 별도 확인해야 한다.
