# 전략맵 CRUD 및 저장 자료 집계

2026-10-23 기준. `/app/strategy-map`과 `/app/strategy-map/:id`를 선택한 워크스페이스의 서버 자료로 전환했다. 클러스터·구성 키워드·관계·집계 스냅샷·자동 분류 이력을 SQLite에 저장한다. 전체 메뉴 완료 여부는 [작업표](full-crud-tasks.md)를 따른다.

## 화면과 데이터 모델

| 모델 | 저장 내용과 작업 |
|---|---|
| `keyword_clusters` | 이름, 우선순위, 메모, 수동/자동 출처, 자동 그룹 키, 수정 버전. 생성·조회·수정·삭제 |
| `keyword_cluster_members` | 클러스터와 키워드 연결. 한 키워드를 여러 그룹에 연결할 수 있으며 구성 전체를 원자적으로 교체 |
| `keyword_cluster_links` | 두 그룹의 관련 주제(양방향) 또는 콘텐츠 지원(방향 있음), 메모. 생성·조회·수정·삭제 |
| `cluster_stats_history` | 생성·구성 변경·명시적 저장·자동 분류 당시 집계와 키워드 목록. 조회·메모 수정·삭제·CSV |
| `cluster_batch_runs` | 자동 분류 알고리즘, 원본 버전, 처리 수, 그룹별 결과, 삭제한 그룹. 조회·메모 수정·삭제·CSV |
| 비공개 `strategy_requests` | 사용자/워크스페이스/요청 키, 요청 지문, 실행 ID. 재요청 시 중복 실행 방지 |

목록에는 검색·우선순위/측정 여부 필터·정렬·10개씩 페이지 이동·현재 필터 전체 CSV를 제공한다. 상세에서는 구성 키워드와 연결 질문, 관계, 집계 이력을 편집한다. 저장 실패 시 모달 입력을 유지한다. 워크스페이스 변경 시 화면 상태를 새로 만들고 해당 ID로 조회·저장한다.

포트폴리오는 검색량 합계를 로그 눈금으로, 평균 난이도를 0~100 눈금으로 표시한다. 둘 중 하나라도 자료가 없으면 해당 그룹은 그래프에서 제외한다. 네트워크 실선은 저장한 관계이고 점선은 공유 키워드/질문에서 계산한 연결이다. 관계 방향은 하단 관계 목록에 표시한다. 그래프는 현재 페이지의 최대 10개 그룹을 표시하며 확대·초기화·확대 후 이동과 상세 이동을 지원한다. 모바일에서는 그래프 내부를 가로로 스크롤하고 본문을 세로로 스크롤한다.

## 집계 정의

- 연결 키워드와 질문 ID는 중복을 제외하고 삭제된 원본은 제외한다. 추적 중 수는 활성 상태이며 일시정지하지 않은 키워드 수다.
- 검색량은 유효한 0 이상 숫자의 합계, 난이도는 0~100인 숫자의 평균이다. 값이 있는 자료 수를 함께 표시하며, 값이 하나도 없으면 `null`/미측정으로 표시한다.
- 질문 인용 비율은 현재 질문의 **문구·언어·국가가 모두 일치**하는 완료 실행 중 질문·엔진별 최신 실행을 사용한다. 불리언 `is_cited`가 있는 실행만 분모에 포함한다. 비율은 인용된 질문·엔진 수 / 측정된 질문·엔진 수이며 출처별 인용률과 다르다.
- 목록과 상세 집계는 현재 원본 및 관계에서 다시 계산한다. 예전 클러스터의 고정 `stats_json`이나 구성원에 복사한 키워드 값은 사용하지 않는다. 명시적으로 저장한 이력은 당시 값을 보존한다.

검색/AI 원본 수집에는 아직 결정적 데모 Provider가 포함된다. 화면에도 이를 표시하며 실제 시장 성과나 AI 의미 유사도로 표현하지 않는다. `집계 스냅샷 저장`은 원본을 재수집하지 않는다.

## 자동 분류와 충돌 처리

`first-term-v1`은 추적 중인 키워드를 NFKC 정규화·소문자 변환한 다음 첫 문자/숫자 단어와 언어·국가로 묶는다. 외부 AI 호출이나 사용량 차감은 없다. 미리보기에 생성/갱신/삭제 그룹 수와 구성원 수를 표시하며 사용자가 확인한 뒤 적용한다.

수동 그룹은 보존한다. 같은 자동 그룹 키는 ID·이름·메모·우선순위를 보존하고 키워드 구성만 다시 계산한다. 구성원이 사라진 자동 그룹은 연결과 집계 이력까지 삭제한다. 수동으로 편집한 자동 그룹의 구성도 다음 자동 분류 시 다시 계산됨을 화면에 안내한다. 한 번에 활성 키워드 1,000개와 전체 클러스터 200개까지 지원한다.

원본 및 관계의 SHA-256 버전이 미리보기 시점과 달라지면 HTTP 409로 거절한다. 미리보기 갱신 후에는 확인 체크를 다시 해야 한다. 적용은 그룹·구성·스냅샷·실행·비공개 요청 기록을 한 저장소 트랜잭션에서 반영한다. 실패하면 전부 롤백한다. 같은 요청 키와 같은 입력은 기존 실행을 반환하며 서버 재시작 후에도 유지된다. 다른 입력에 같은 키를 재사용할 수 없고, 실행 이력을 삭제해도 요청 기록을 유지하여 재실행을 막는다.

일반 수정/삭제/구성 변경/스냅샷 저장은 `expected_revision`을 검사한다. 다른 작업이 먼저 수정한 경우 HTTP 409를 반환하며 사용자의 입력을 유지한다.

## API·권한·삭제

`GET /api/v1/strategy-map?workspace_id=…`는 인증과 워크스페이스 멤버십을 확인하고 `private, no-store`로 집계 자료를 반환한다. 쓰기는 `/api/v1/functions/:name`의 전용 명령으로 수행한다.

- `cluster-create/update/delete`, `cluster-members-set`, `cluster-refresh`
- `cluster-link-create/update/delete`
- `cluster-history-update/delete`, `strategy-run-update/delete`
- `strategy-map-preview`, `strategy-map-orchestrator` (`strategy-map-cluster` 별칭)

위 다섯 공개 테이블의 REST 쓰기는 차단한다. 이름 길이/중복, 메모 길이, 우선순위, 최대 구성원 수, 중복 구성원, 다른 워크스페이스 참조, 자기 자신과의 관계, 중복 관계를 검증한다. 측정값은 사용자가 직접 수정할 수 없다. 이전 `strategy-map-link-prompts` 함수는 임의 연결 수를 반환하지 않고 실제 키워드-질문 연결 기능을 사용하도록 안내한다.

클러스터 삭제 시 구성·관계·집계 스냅샷을 삭제하고 원본 키워드/질문 및 자동 분류 실행 스냅샷은 남긴다. 원본 키워드 삭제 시 기존 삭제 정책에 따라 구성을 정리하며 현재 집계/연결선에 반영한다. 워크스페이스 삭제 시 비공개 중복 요청 기록도 정리한다.

## 검증과 증거

전체 단위 테스트 **146/146**, 전체 E2E **50/50**, 백엔드 계약 **22/22**, 타입 검사와 Next.js 빌드를 통과했다. 질문 언어·국가 변경 제외 조건을 추가한 뒤 전략 단위 테스트 **8/8**을 다시 통과했다. 실제 브라우저에서 발견한 원본 캔버스의 `overflow: hidden` 문제를 수정한 뒤 최종 빌드 및 휠 스크롤을 포함한 전략 E2E **3/3**을 통과했다.

`npm run verify:routes -- http://localhost:3000`도 363개 경로의 렌더링/매니페스트/로컬 자산 검사에서 실패 없이 통과했다. 이는 원본 404 안내 73개를 포함한 경로 검사이며, 모든 메뉴의 CRUD 완료를 의미하지 않는다.

단위 검사는 권한/충돌, 최신 실행 집계, 미측정, 수동·파생 관계, 연쇄 삭제, 자동 분류 ID 보존, 원자성, 재시작 후 중복 차단, 이력 불변성을 포함한다. E2E는 실제 API 및 실행별 독립 SQLite에서 CRUD·새로고침·미리보기 충돌·실패 입력 보존·모바일·CSV·교차 워크스페이스 차단을 확인한다.

Ego Lite에서는 별도 검증 워크스페이스에서 그룹 생성, 자동 분류, 관계 생성/메모 수정, 새로고침 후 유지, 실제 휠 스크롤, 데스크톱/390px 모바일 화면을 확인했다. 검증 워크스페이스는 이후 삭제했다.
