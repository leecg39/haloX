# 등록 URL CRUD와 SERP/AIO/GEO 관측

2026-10-24. S07 `/app/settings?tab=earned`를 영속 화면으로 전환했다. 원본 `2011d43675e4e37c.json`의 등록 URL/CSV 기능을 기준으로 구현했다. 전체 메뉴 진행은 [작업표](full-crud-tasks.md)를 따른다.

## 화면과 API

설정 메뉴·공통 검색·SEO/GEO 분석의 ‘등록 URL 관측’에서 접근한다. URL·제목·채널·발행일·메모를 등록/조회/수정/삭제하고 검색·채널/관측 상태 필터·정렬·페이지 이동을 제공한다. 제목과 메모를 포함한 모든 값은 현재 선택한 워크스페이스의 `earned_publications`에 저장한다. 목록 CSV는 현재 필터 결과 전체이며 UTF-8 BOM과 수식 셀 보호를 적용한다.

`GET /api/v1/earned?workspace_id=...&start=YYYY-MM-DD&end=YYYY-MM-DD`는 등록 정보·기간별 관측·출처·권한을 반환한다. `POST`는 `create`, `update`, `delete`, `preview`, `import` 명령을 사용한다. 쓰기·미리보기는 기타 메뉴 쓰기 권한이 필요하며, 분석 메뉴 조회 권한이 없으면 등록 정보만 반환한다. 뷰어는 조회만 가능하다. 외부 URL 등록은 콘텐츠 관리 작업이므로 쓰기 권한이 있는 일반 멤버도 사용할 수 있다.

수정·삭제는 `expected_revision`으로 동시 수정을 검사한다. 실패나 충돌은 폼 입력을 유지한다. 생성과 CSV 가져오기의 요청 키·입력 지문·결과 ID는 비공개 `earned_requests`에 저장한다. 같은 요청 재전송은 현재 남은 결과를 반환하며, 삭제한 결과를 다시 만들지 않는다. 같은 키의 다른 입력은 거절한다. 워크스페이스 삭제 시 요청 기록도 정리한다. 직접 REST 변경으로 검증·버전·중복 처리를 우회할 수 없다.

## URL과 CSV 규칙

- 공개 HTTP/S 표준 포트 URL, 최대 2,000자. 인증 정보·공백/제어 문자·로컬/내부 IP·지원하지 않는 프로토콜을 거절한다. 등록 시 외부 요청이나 DNS 조회를 하지 않는다.
- URL 표준 정규화와 fragment 제거를 적용한다. HTTP/HTTPS, 경로 끝 `/`, 쿼리 값/순서는 별개다. 추적 쿼리나 별칭을 추정해 합치지 않는다. 같은 워크스페이스의 정규화 URL은 중복 등록할 수 없다.
- 제목 200자, 채널 60자(생략하면 호스트의 앞 60자), 메모 5,000자, 발행일은 선택 YYYY-MM-DD다. 발행일은 관리용 메타데이터이며 관측 기간을 자동 변경하지 않는다.
- 워크스페이스당 2,000개, CSV당 1MiB·500행. 헤더 `url`은 필수이며 `title`, `channel`, `published_at`, `notes`는 선택이다. 따옴표 안 쉼표/줄바꿈과 이중 따옴표를 지원한다. 잘못된 따옴표·열 수·중복 헤더·알 수 없는 헤더·중복 URL·잘못된 행은 전체 파일을 거절한다.
- 파일 업로드 후 미리보기로 모든 행을 검증한다. 저장 시 파일의 지문과 기존 등록 목록의 버전을 다시 확인한다. 그 사이 다른 등록 정보가 바뀌었으면 새 미리보기를 요구한다. 일부 행만 먼저 저장하지 않는다. 미리보기 페이지 이동은 저장 버튼을 제출하지 않는다.

## 실제 저장 근거의 별도 집계

기본 최근 28일, UTC 최대 366일의 기간을 지원한다. 기간 내 **모든 유효 표본**에서 같은 등록 URL의 등장 횟수를 센다. 기존 SEO 분석의 키워드/엔진별 최신 표본 요약과 집계 기준이 다르므로 화면에 표본 수와 기준을 표시한다.

| 구분 | 근거와 집계 |
|---|---|
| SERP | `serp_snapshots.top_results_json`의 정확한 URL 일치. 표본당 한 번, 중복 위치는 가장 좋은 순위. 기간 내 최고 순위를 별도 표시 |
| AIO | AI 요약이 감지된 표본의 `ai_overview_json.cited_urls`. 도메인만 있는 자료는 개별 URL 인용 여부를 알 수 없으므로 미확인 |
| GEO | 완료된 `geo_prompt_runs`에 연결된 `geo_citations.cited_url`. 같은 실행 안의 중복 URL은 한 번 |

현재 키워드/질문의 문구·언어·국가가 수집 당시와 일치하고 유효한 수집 시각이 있는 표본을 사용한다. 삭제된 엔티티·미완료 실행·잘못된 시각 등은 제외한다. 표본이 없으면 미확인, 읽은 목록에 주소가 없으면 0회다. GEO 0회는 저장된 완료 실행의 인용 목록에서 찾지 못했다는 의미이며 전체 웹에서 인용되지 않았음을 보장하지 않는다.

관측 근거에는 원본 URL·검색어/질문·엔진·시각·Provider·순위를 표시하고 해당 수집 항목의 이력으로 연결한다. 상세는 최근 100건을 표시하며 전체 건수도 함께 보여 준다. 데모/가져온 자료도 포함되므로 출처를 표시하며 이를 실제 시장 성과로 단정하지 않는다. 등록 주소나 원본이 변경/삭제되면 다음 조회에서 다시 계산한다. 원본 측정값·자사 분류·기존 리포트는 수정하지 않는다.

SEO Raw 가져오기 형식에 선택 `ai_overview.cited_urls`(최대 100개)를 추가했다. 생략/null은 미제공이고 명시적인 `[]`는 빈 URL 목록이다. 과거 도메인만 있는 자료에서 개별 URL을 만들어내지 않는다. 원본 JSON과 출처는 기존 Raw 가져오기 보관 규칙을 따른다. [Raw 데이터 형식](raw-data-crud.md).
