# 페르소나·지식허브 CRUD

2026-10-23. `/app/personas`와 `/app/knowledgehub`의 목록과 동적 상세는 현재 워크스페이스의 SQLite 데이터를 사용한다.

## 모델과 화면

| 모델 | 화면에서 가능한 작업 |
|---|---|
| `writing_style_profiles` | 이름·설명·대상 독자·문체·금지어 CRUD, 검색, 기본 페르소나 지정 |
| `writing_style_samples` | 페르소나별 예문 제목·본문·원문 URL CRUD |
| `knowledge_entities` | 자료 이름·유형·설명·본문·대표 URL CRUD, 이름/본문 검색·유형 필터 |
| `knowledge_entity_sources` | 자료별 텍스트/URL 출처 CRUD, 파일 업로드·메타/요약 수정·원본 다운로드·삭제 |
| `evidence_contexts` | 자료별 근거 메모 CRUD, 해당 자료의 출처 연결/해제 |
| `keyword_knowledge_entities` | 키워드 연결·조회·변경·해제, 키워드 상세로 이동 |

`/app/personas/:id`, `/app/knowledgehub/:id`를 직접 열거나 새로고침해도 동일 항목을 읽는다. 워크스페이스 전환 시 화면 상태를 다시 만들고 해당 공간의 ID로 조회/저장한다. 검색 결과 없음·자료 없음·권한 오류·저장 실패를 구분한다. 저장 오류 시 입력한 폼은 유지한다.

동일 워크스페이스에서 이름 중복을 거부한다. 기본 페르소나는 최대 하나다. 길이·배열·자료 유형·HTTP(S) URL과 모든 부모 참조를 서버에서 검증한다. `updated_at` 조건을 이용해 오래된 화면의 편집/삭제를 거부한다.

## API와 파일 보관

- `GET /api/v1/library?workspace_id=…`: 소속을 확인하고 관련 9개 테이블을 동일 읽기 스냅샷으로 반환한다. 바이너리 원본은 이 응답과 REST 목록에 포함하지 않는다.
- 텍스트/메타 CRUD: 기존 `/api/v1/rest/:table`. 편집 가능한 필드를 제한하며 파일 바이너리나 메타데이터를 임의 생성할 수 없다.
- `POST /api/v1/library/files`: `workspace_id`, `knowledge_entity_id`, `title`(선택), `file`을 multipart로 전달한다.
- `GET /api/v1/library/files/:sourceId`: 인증·워크스페이스 소속 확인 후 원본 바이트를 다운로드한다. `attachment`, `nosniff`, `private, no-store` 응답을 사용한다.

허용 파일: PDF·TXT·MD, 파일당 5MB, 워크스페이스당 원본 합계 50MB. 요청 본문은 multipart 파싱 전에 크기를 제한한다. PDF 헤더, UTF-8 디코딩, 바이너리 문자, 파일명 경로/제어문자를 검사한다. TXT·MD는 10만 자 이하이며 원본 바이트와 읽은 본문을 모두 저장한다. PDF는 원본 보관만 하며 본문 자동 추출은 하지 않는다. 사용자가 출처 편집에서 요약을 입력할 수 있다. URL도 자동 크롤링하지 않고 입력한 원문/요약을 저장한다.

원본은 공개 정적 폴더가 아닌 같은 SQLite의 비공개 `knowledge_files` 컬렉션에 base64로 보관한다. SHA-256·파일명·MIME·바이트 수만 출처 메타데이터에 저장한다. 자료/출처와 파일 삭제가 같은 트랜잭션에 들어가므로 별도 파일 경로의 정리 실패가 없다. 파일 전체를 상태 스냅샷으로 읽는 로컬 구현이며 대규모 파일 운영은 객체 저장소 어댑터가 필요하다.

## 콘텐츠 참조와 삭제 정책

페르소나/자료 상세에서 **초안 생성**을 누르면 주제, 페르소나, 참조 자료를 선택할 수 있다. `content-draft`는 선택 항목의 소속을 사용량 차감 전에 검증한다. 명시적인 페르소나 선택이 없으면 기본 페르소나를 쓰며, null은 사용 안 함이다.

생성기는 문체·금지어·예문, 자료 본문·출처·근거 메모를 전달받고 `content_jobs.generation_context`에 당시 내용을 저장한다. 현재 결정적 데모 생성기는 작성 지침과 참조 내용을 초안에 포함한다. 실제 LLM의 문체 변환이나 금지어 준수를 보장하는 기능은 아니다. 외부 AI 호출·자동 게시 없이 실제 초안 레코드를 저장하며 상세에서 다시 읽을 수 있다.

- 페르소나 삭제: 예문 삭제, 콘텐츠의 페르소나 연결 해제. 기존 초안과 생성 당시 내용 유지.
- 자료 삭제: 출처·파일·근거·키워드 연결 삭제, 콘텐츠의 현재 자료 ID 제거. 기존 초안과 참조 스냅샷 유지.
- 출처 삭제: 원본 파일 삭제, 근거 메모의 출처 연결을 null로 바꿔 메모 보존.
- 워크스페이스 삭제: 해당 공간의 파일을 포함해 정리.

공개 REST로 참조 스냅샷을 수정할 수 없다. 생성 요청 키 재사용으로 사용량을 우회하는 요청도 거부한다. `rpc-cache`를 통한 사용량 예약/확정/해제 우회 경로 역시 차단한다.
